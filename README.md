# Gen Release Watch

Runway Gen-4.5 arrived on December 1, 2025 with a 720p ceiling, a 12-credit-per-second meter and a Standard-plan gate. The specifics, without the launch-reel gloss.

**Read the full page:** https://runway-gen-4-5.github.io/

Gen-4.5 is for people already paying for a Runway Standard plan or higher who want the current top-rated text-to-video model and can work inside a 10-second, 720p envelope. It is not for anyone who needs long-form output, a desktop app, or a model they can call from their own backend, because the spec sheet lists web as the only platform. The one caveat worth knowing before you budget: the cost is quoted in credits per second, not dollars, so your real cost per finished clip depends on your plan's credit price and on how many takes you discard. If you want browser video generation without a Runway subscription at all, Kyncept runs Veo 3.1 for text-to-video and image-to-video.
